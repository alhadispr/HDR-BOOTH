# Webcam capture test

1. Install the app on Windows 10/11 x64.
2. In Windows Settings > Privacy & security > Camera, allow camera access and desktop apps.
3. Connect a USB webcam, or expose a compatible Canon camera through Canon EOS Webcam Utility.
4. Open HDR BOOTH > Sessions and create a session.
5. Open Studio > Hubungkan Kamera and approve the camera permission if prompted.
6. Confirm live preview, select mirror if desired, then take a test photo.
7. Confirm a JPEG appears under `Pictures/HDR BOOTH/<session>/` and in the selected session's Gallery.
8. Close and reopen the app and confirm the session and image record remain.

This test validates the webcam path only. It does not validate direct Canon EDSDK shutter control or Epson printing.
