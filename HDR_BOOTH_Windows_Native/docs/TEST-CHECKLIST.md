# Checklist penerimaan

- [ ] `npm install` selesai tanpa error
- [ ] `npm run tauri dev` berhasil
- [ ] `npm run tauri build` menghasilkan installer
- [ ] Aplikasi dapat dibuka setelah restart Windows
- [ ] Database tetap ada setelah restart
- [ ] Buat sesi, tutup sesi, buka kembali sesi
- [ ] Webcam / EOS Webcam Utility terdeteksi dan preview tampil
- [ ] Foto tersimpan dan dapat dibuka dari Galeri
- [ ] Uji beberapa kali capture dan pastikan nama file unik
- [ ] Uji frame PNG dengan alpha transparan
- [ ] Uji voucher valid, nonaktif, kedaluwarsa, dan kuota habis
- [ ] Uji printer dan media aktual (belum tersedia pada build ini)
- [ ] Uji backup dan pemulihan
- [ ] QR, cloud, serta pembayaran hanya dinyatakan siap setelah integrasi dan pengujian server-side
